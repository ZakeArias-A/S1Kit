# 决策功能对照

[文档首页](README.md)

依据 [TypeSafe 官方 API 文档](https://docs.typesafe.ai/api)，对照的是 Python 工具集的决策能力，不提供 HTTP 服务或相同网络协议。

| 功能 | S1Kit |
|---|---|
| 自定义 state：字符串、对象、数组 | 支持，另接受其他有限 JSON 值 |
| 结构化 instructions | 支持字符串、对象、数组 |
| Choice 描述 | 支持字符串、对象、数组、null |
| Choice 最多 255 项 | 支持 2–255 项，受标签与上下文约束 |
| Score 2–10 个有序等级 | 支持字符串、对象、数组，返回索引期望 |
| Noul 自定义 false/true 条件 | 支持 |
| 全部候选概率、Choice/Score confidence | 支持，本地概率未经校准 |
| 多题及自定义问题键 | 支持，逐题独立前向 |
| 模型选择 | 调用方加载并绑定模型 |
| Token 用量 | 返回前向输入合计；没有生成 token |
| 自定义系统提示词 | 支持引擎默认与按次覆盖，属于额外能力 |
| 多模态证据 | 自定义预处理接入，要求基座支持 |

结果使用 `questions[id].answer`，不是 TypeSafe 的响应格式。认证、模型列表与服务配额属于托管服务功能，不由本地决策库实现。

功能对应不意味着质量相同。上下文容量、准确率、校准、速度与媒体能力取决于基座和运行配置。超过 26 项默认使用数字标签；不满足稳定单 token 编码时须配置 `labels`，否则明确报错。不能保证任意 LLM 都支持 255 项一次读出。

[已有基准结果](../benchmarks/README.md)使用原有默认提示词，不能作为自定义提示词或 255 项任务准确率的证据。
